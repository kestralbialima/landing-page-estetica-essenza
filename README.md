# 💎 Landing Page Premium - Clínica de Estética Essenza

Protótipo de alta conversão desenvolvido pela **Core.Build**, focado em profissionais da área da estética que buscam elevar sua autoridade digital e transformar cliques em agendamentos.

## ✨ Características do Projeto

O design foi estruturado para transmitir luxo e confiança, utilizando uma paleta de cores nude e dourada.

* **Design Minimalista & Elegante**: Uso de tipografia serifada (Playfair Display) para reforçar o posicionamento premium.
* **Foco em UX/UI**: Navegação fluida com scroll suave e elementos interativos.
* **Cards de Procedimentos**: Janelas modais detalhadas para explicar cada serviço sem sobrecarregar a página principal.
* **Seção de Ambiente Estilo Vídeo**: Container com proporção 16:9 e botão de play estilizado para tour virtual da clínica.
* **Totalmente Responsivo**: Adaptado para uma experiência impecável em dispositivos móveis.
* **Mapa Interativo**: Integração com Google Maps customizada para facilitar a chegada do cliente.

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **Tailwind CSS**: Para estilização rápida e moderna.
* **JavaScript (Vanilla)**: Para controle de modais e animações de scroll.
* **Google Fonts**: Fontes Inter e Playfair Display.
